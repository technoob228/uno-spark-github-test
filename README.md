# uno-spark-github-test

Test repository for **Deploy Sparks from GitHub** in Uno: each folder is one Spark.

- `js/` — JavaScript (`index.js` + a relative import)
- `python/` — Python (`main.py` + a helper module)
- `ts/` — TypeScript only (`src/index.ts`): Uno adds a one-line `index.js`

Every push to `main` deploys them again. Nothing secret here.
